# Modelos Archivados

Este directorio contiene modelos alternativos que no están siendo usados activamente en el sistema principal.

## Modelos Archivados

- **document_unified.py**: Modelo unificado que combina funcionalidades de Document y DocumentEnhanced. No está siendo usado actualmente.

## Modelos Activos

Los siguientes modelos están en uso y se mantienen en el directorio principal:

- **document.py**: Modelo base de documentos (usado activamente)
- **user.py**: Modelo base de usuarios (usado activamente)
- **document_enhanced.py**: Modelo mejorado con funcionalidades avanzadas (usado en algunos servicios)
- **user_enhanced.py**: Modelo mejorado de usuarios (usado internamente)
- **models_v2.py**: Sistema completo de modelos V2 (usado como alternativa en __init__.py)
- **organization.py**: Modelo de organizaciones
- **processing.py**: Modelos de procesamiento

## Nota

Si necesitas usar alguno de estos modelos archivados, puedes moverlos de vuelta al directorio principal y actualizar los imports correspondientes.
